Daftar Stiker
0 stiker
Belum ada stiker. Tambahkan lewat panel di kiri.
Pakai tab "Stiker IMEI" / "Stiker Sparepart" / "Stiker Flashsale" di paling atas untuk pindah mode — masing-masing punya daftar, pencarian, dan riwayat cetak sendiri-sendiri. Item dengan label BARU adalah yang baru kamu tambahkan sesi ini (belum pernah dicetak) — data lama tidak diberi label. Pilih "Hanya Data Baru" di atas untuk cetak/PDF/Excel khusus data baru saja — muncul dropdown tambahan untuk menyaring lagi berdasarkan tanggal masuk. Setelah selesai, tekan "Tandai Baru → Sudah Ada" supaya batch berikutnya mulai bersih lagi. Grid stiker IMEI/Sparepart: 4 kolom, saling berdempetan tanpa jarak (garis putus-putus antar stiker menyatu jadi satu garis potong, bukan dua garis dengan celah kosong di tengahnya — jadi cukup satu kali gunting lurus per baris/kolom), ukuran asli 40×20mm, tersusun dalam aturan tetap 13 baris × 4 kolom = 52 stiker per halaman. Grid stiker Flashsale ukurannya lebih besar (60×30mm), tersusun 9 baris × 3 kolom = 27 stiker per halaman. Kertas default F4/Folio (215×330mm) — di F4 tersedia ±60mm ruang sisa untuk 13 baris (jauh di bawah batas maksimumnya yang sekitar 16 baris), jadi sangat aman dari risiko kepotong — kalau data lebih dari kapasitas satu halaman, sisanya otomatis lanjut ke halaman baru. Setiap stiker dijamin utuh, tidak terpotong di antara dua halaman. Untuk PDF, pilih tujuan "Simpan sebagai PDF". Di kotak dialog cetak, set Margins ke "None" dan matikan "Headers and footers" (biasanya di "More settings") — ini penting supaya ruang cetak benar-benar penuh dipakai, bukan disisakan browser untuk judul/tanggal/URL. Set printer ke ukuran asli/100%. Daftar ini otomatis tersimpan ke database, bisa diakses dari perangkat mana pun.
